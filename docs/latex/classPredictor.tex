\doxysubsection{Detailed Description}
Estimates the probability of the next bit being 0 or 1. 

The \doxylink{classPredictor}{Predictor} uses 3 context models (order-\/0, order-\/1, Order-\/2) and mixes their predictions using a stretch/\+squash logistic regression model updated dynamically via gradient descent.
